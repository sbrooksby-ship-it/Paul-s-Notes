# Team Brain Quick Start

*3 files. 5 minutes. You're live.*

---

## 1. Open the Vault

- Open Obsidian → **File → Open folder as vault**
- Navigate to: `Downloads\Team-Brain`
- Open `Master-Dashboard/Welcome.md` — read the overview

## 2. Try the Recorder (1 minute)

- Open `Resources/Recorder.html` in Chrome or Edge (double-click it)
- Click the big circle to start recording
- Talk for 10 seconds
- Click stop → name it → save
- The file downloads to your browser's download folder

**Pro tip:** In your browser settings, set the download folder to `Downloads/Team-Brain/Recordings/Audio/`. Then every recording automatically lands in the right place.

**Keyboard shortcuts:** Space = start/stop recording. Enter = save. Escape = discard.

## 3. Send a Recording to Paul

- Drag the recording file into a Hermes chat with **@paul**
- Or tell Paul: *"Process the latest recording"*
- Paul transcribes, creates a 1-on-1 note, updates the profile, extracts action items

## 4. Use Your Phone for Dumps

- After your next 1-on-1, open your phone's voice memo app
- Record 2 minutes
- Email/AirDrop/send the file to your computer
- Drag it into chat with Paul
