## How to Use the New Stuff

### Daily Log
At the end of each day (or start of next), create a note:
- Open `Templates/Daily-Log.md`
- Copy it
- Create `Daily/YYYY-MM-DD - DayName.md`
- Fill it in

Or just write directly — no template required, but the template gives you structure.

### New Meeting
When any meeting happens that isn't a 1-on-1:
1. Create `Meetings/YYYY-MM/YYYY-MM-DD - Meeting Name.md`
2. Use `Templates/Meeting-Note.md` as a starting point (or just write it)
3. File action items in `Master-Dashboard/Action Items.md`

### Project
When you start tracking a project:
1. Create `Projects/Project Name.md`
2. Use `Templates/Project-Note.md` as a starting point
3. Link it from meeting notes, daily logs, wherever it comes up
